# Black Meridian weapon presentation assets

The six meshes in `Meshes/` are original low-poly development assets made
for this project:

- `SM_BM_ARX4_Rifle` — standard rifle used by Vanta riflemen.
- `SM_BM_Kestrel9_SMG` — compact weapon used by assault enemies.
- `SM_BM_Rook_DMR` — long-range rifle used by marksmen.
- `SM_BM_Breach12_Shotgun` — close-range shotgun profile.
- `SM_BM_Solace_Pistol` — compact sidearm profile.
- `SM_BM_Arc7_Launcher` — single-shot launcher profile.

Each mesh is authored around the top of the pistol grip and contains `Grip` and
`Muzzle` static-mesh sockets. The runtime attaches the weapon actor to Manny's
`hand_r` socket, resolves the authored `Grip` through `ABMWeapon::GetGripLocation`
so a hidden fallback component cannot offset the gun, and resolves the
authoritative trace, muzzle flash, and tracer from the mesh's `Muzzle` socket.
A hidden cylinder locator remains only as a compatibility fallback for older
replacement meshes. The weapon data, ammo, reload, damage, spread, and
replication remain in `ABMWeapon`; these assets are presentation replacements
and can be swapped for final art without changing the firing contract.

The assets are generated by the editor automation test
`BlackMeridian.Combat.WeaponAssets` so they can be recreated when the engine
version or final art pipeline changes. The same test migrates existing packages
to add the sockets, resolves all six firearm profiles to these meshes when a
third-person presentation is requested, and verifies the runtime muzzle
location matches the authored socket. They use Unreal's licensed default
material only as a development placeholder; replace the material and meshes
with owned or explicitly licensed production art before release.
